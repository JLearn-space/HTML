## Блок 1. Тег `<img>`: src, alt, width, height

**Простыми словами:** если ссылка `<a>` - это дверь на другую страницу, то `<img>` - это окно, через которое на вашу страницу "вставляется" картинка, которая физически хранится отдельным файлом.

Тег `<img>` - **непарный**, как `<br>` и `<hr>` из урока 2. У него нет содержимого и закрывающего тега - вся информация передаётся через атрибуты.

```html
<img src="cat.jpg" alt="Рыжий кот сидит на подоконнике">
```

Разберём атрибуты по порядку.

### `src` (source) - откуда брать изображение

**Обязательный** атрибут - путь к файлу изображения. Работает по тем же правилам путей, что мы разобрали в уроке 3: относительный путь для своих файлов, абсолютный - для изображений с внешних сайтов.

```html
<img src="images/cat.jpg" alt="Кот">
```

```html
<img src="https://example.com/images/cat.jpg" alt="Кот">
```

### `alt` (alternative text) - альтернативный текст

**Обязательный** атрибут, хотя формально браузер не откажется работать без него. Это текстовое описание изображения, которое отображается:

- если картинка не загрузилась (сломанная ссылка, проблемы с интернетом);
- скринридером - незрячий пользователь услышит именно этот текст вместо изображения;
- поисковыми системами - Google и другие поисковики используют `alt`, чтобы понять, что на картинке (сами картинки они "видеть" в привычном смысле не умеют).

```html
<img src="cat.jpg" alt="Рыжий кот сидит на подоконнике и смотрит в окно">
```

**Как писать хороший `alt`:** описывайте, что изображено, кратко и по существу - как будто объясняете картинку человеку по телефону. Не пишите просто "картинка" или "изображение1" - это бесполезно.

**Особый случай - декоративные изображения:** если картинка чисто декоративная и не несёт смысловой информации (например, орнамент-разделитель), `alt` оставляют **пустым**, но не убирают полностью:

```html
<img src="decorative-line.png" alt="">
```

Пустой `alt=""` сообщает скринридеру "эту картинку можно пропустить, она не несёт информации" - это осознанное решение, а не забытый атрибут.

### `width` и `height` - размеры изображения

Задают ширину и высоту в пикселях.

```html
<img src="cat.jpg" alt="Рыжий кот на подоконнике" width="400" height="300">
```

**Зачем указывать размеры, если картинку всё равно можно растянуть через CSS:** браузер, пока изображение ещё загружается, заранее резервирует место на странице нужного размера. Без этого текст вокруг картинки будет "прыгать" в момент, когда изображение наконец загрузится и займёт своё место - такой эффект называют CLS (сдвиг макета), и он ухудшает восприятие сайта.

**Важно про пропорции:** если вы укажете `width` и `height`, не соответствующие реальному соотношению сторон картинки, изображение исказится (растянется или сожмётся неестественно). Указывайте либо оба значения в правильной пропорции, либо только одно - тогда браузер сам вычислит второе, сохранив пропорции.

```html
<img src="cat.jpg" alt="Рыжий кот на подоконнике" width="400">
```

### Частые ошибки новичков

| Ошибка                                                                                | Как исправить                                                                                     |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Забывают `alt` полностью                                                              | Указывайте `alt` всегда - с описанием или пустым `alt=""` для декоративных картинок               |
| Пишут в `alt` бесполезный текст: `alt="картинка"`, `alt="img1"`                       | Описывайте содержимое изображения по существу: `alt="Рыжий кот на подоконнике"`                   |
| Указывают `width`/`height` в неправильной пропорции - картинка искажается             | Сохраняйте реальное соотношение сторон, либо указывайте только один размер                        |
| Используют `<img>` как замену `<a>` для перехода на другую страницу (пишут `onclick`) | Если изображение должно быть кликабельным как ссылка - оберните `<img>` в тег `<a>` (пример ниже) |

**Изображение-ссылка:**

```html
<a href="about.html">
    <img src="logo.png" alt="Логотип компании - перейти на страницу О нас" width="150">
</a>
```

## Блок 2. Форматы изображений: JPEG, PNG, SVG, WebP

Важно понимать, что разные форматы файлов подходят для разных типов изображений - использование "не того" формата приводит либо к раздутому весу файла, либо к потере качества.

### JPEG (.jpg, .jpeg)

Подходит для **фотографий** - сложных изображений с плавными цветовыми переходами (закаты, портреты, пейзажи). Использует сжатие с потерей качества - чем сильнее сжат файл, тем он легче, но тем заметнее артефакты.

```html
<img src="sunset-photo.jpg" alt="Закат над горами">
```

**Не подходит для:** текста, логотипов с чёткими линиями и однотонными областями - при сжатии JPEG на резких границах появляются "грязные" пятна артефактов.

### PNG (.png)

Подходит для **изображений с прозрачным фоном** и **графики с чёткими краями** - логотипы, иконки, скриншоты интерфейсов. Сжатие без потери качества, но за это файл весит больше, чем JPEG для той же фотографии.

```html
<img src="logo-transparent.png" alt="Логотип компании на прозрачном фоне">
```

### SVG (.svg)

**Векторный** формат - в отличие от JPEG/PNG (которые хранят изображение как сетку пикселей), SVG хранит математическое описание фигур. Благодаря этому SVG **масштабируется без потери качества** на любой размер - идеально для логотипов и иконок, которые могут отображаться и крошечными, и на весь экран.

```html
<img src="icon-star.svg" alt="Иконка звезды">
```

**Особенность:** SVG-файл - это, по сути, текстовый XML-файл, который можно открыть и посмотреть код. Это делает файлы очень лёгкими для простой графики.

### WebP (.webp)

Современный формат от Google, который сочетает преимущества JPEG и PNG - хорошее сжатие фотографий **и** поддержку прозрачности, при этом обычно весит меньше, чем аналогичный JPEG или PNG. Поддерживается всеми современными браузерами.

```html
<img src="photo.webp" alt="Фотография городского пейзажа">
```

### Сравнительная таблица

| Формат | Лучше всего для                              | Прозрачность | Вес файла                              |
| ------ | -------------------------------------------- | ------------ | -------------------------------------- |
| JPEG   | Фотографии                                   | Нет          | Средний/маленький (с потерей качества) |
| PNG    | Логотипы, скриншоты, графика с прозрачностью | Да           | Больше, чем JPEG                       |
| SVG    | Иконки, логотипы (векторная графика)         | Да           | Очень маленький для простой графики    |
| WebP   | Универсальный - фото и графика               | Да           | Обычно меньше, чем JPEG/PNG            |

---

### Частые ошибки новичков

| Ошибка                                                           | Как исправить                                                                                |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Используют PNG для фотографий                                    | Для фото используйте JPEG или WebP - файл будет значительно легче                            |
| Используют JPEG для логотипа с прозрачным фоном                  | JPEG не поддерживает прозрачность - используйте PNG или SVG                                  |
| Вставляют огромные фотографии "как есть" с камеры (несколько МБ) | Сжимайте изображения перед использованием на сайте - большой вес замедляет загрузку страницы |

## Блок 3. `figure` и `figcaption` - подписи к изображениям

Когда изображению нужна подпись (как в книге или журнале - "Рис. 1. Схема работы устройства"), используется связка тегов `<figure>` и `<figcaption>`.

```html
<figure>
    <img src="chart.png" alt="График роста продаж за 2025 год" width="500">
    <figcaption>Рис. 1. Рост продаж компании в 2025 году</figcaption>
</figure>
```

`<figure>` — семантическая обёртка, обозначающая "это самостоятельный блок иллюстративного контента" (изображение, диаграмма, код и т.д.), `<figcaption>` — его подпись, может быть размещена до или после содержимого `<figure>`.

**Почему не просто `<img>` + `<p>` рядом:** `<figure>`/`<figcaption>` явно связывает изображение и подпись как единое целое семантически - это важно для скринридеров и для структурной ясности документа, в отличие от двух независимых элементов, стоящих рядом чисто визуально.

## Мини-задание

Самостоятельно вставьте изображение логотипа `logo.png`, лежащего в папке `images`, с шириной 200px и подходящим `alt`-текстом, а также подписью через `figcaption` "Логотип нашего сайта".

**Решение:**

```html
<figure>
    <img src="images/logo.png" alt="Логотип сайта — стилизованная буква S" width="200">
    <figcaption>Логотип нашего сайта</figcaption>
</figure>
```

## Блок 5. `<audio>` и `<video>` - встраивание медиа

### `<audio>` — аудио на странице

```html
<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    <source src="music.ogg" type="audio/ogg">
    Ваш браузер не поддерживает воспроизведение аудио.
</audio>
```

Разберём:

- `controls` - атрибут (без значения), который включает видимую панель управления (play/pause, громкость, перемотка). Без него аудио загрузится, но у пользователя не будет видимых кнопок управления.
- `<source>` - непарный тег внутри `<audio>`, указывающий на файл. Можно указать **несколько** `<source>` с разными форматами - браузер выберет первый поддерживаемый формат. Это нужно, потому что не все браузеры поддерживают все аудиоформаты одинаково.
- Текст `Ваш браузер не поддерживает...` - это **запасной вариант (fallback)**, который покажется только в очень старых браузерах, не понимающих тег `<audio>` вообще.

### `<video>` - видео на странице

```html
<video controls width="640" height="360">
    <source src="lesson.mp4" type="video/mp4">
    <source src="lesson.webm" type="video/webm">
    Ваш браузер не поддерживает воспроизведение видео.
</video>
```

Принцип полностью аналогичен `<audio>`, плюс есть дополнительные полезные атрибуты:

```html
<video controls width="640" height="360" poster="preview.jpg" muted loop>
    <source src="lesson.mp4" type="video/mp4">
</video>
```

- `poster` - изображение-заглушка, которое показывается **до** начала воспроизведения (аналог обложки видео на YouTube).
- `muted` - видео стартует без звука.
- `loop` - видео зацикливается после окончания.
- `autoplay` - автоматический запуск при загрузке страницы (используйте **осторожно**: большинство браузеров блокируют автовоспроизведение со звуком без явного действия пользователя - это сделано специально, чтобы сайты не "орали" на пользователя внезапно).

**Важное правило доступности:** если видео содержит важную речь/диалоги, по-хорошему стоит предусмотреть субтитры (тег `<track>`, который выходит за рамки этого вводного урока, но полезно знать, что такая возможность существует).

### Частые ошибки новичков

| Ошибка                                                   | Как исправить                                                                                                                                                               |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Забывают атрибут `controls`                              | Без него у пользователя не будет видимой панели управления воспроизведением                                                                                                 |
| Указывают только один `<source>`                         | Добавляйте минимум два формата (например, mp4 + webm) для совместимости с разными браузерами                                                                                |
| Используют `autoplay` со звуком без острой необходимости | Большинство браузеров всё равно заблокирует это - используйте `autoplay` вместе с `muted`, если действительно нужен автозапуск                                              |
| Вставляют огромные видеофайлы напрямую на сайт           | Для реальных проектов лучше использовать сервисы вроде YouTube с `<iframe>`-встраиванием (эта тема выходит за рамки текущего урока - рассмотрим при необходимости отдельно) |

## Блок 6. Favicon - иконка сайта

Favicon - маленькая иконка, которая отображается на вкладке браузера рядом с `<title>`, а также в закладках и истории посещений.

Подключается через тег `<link>` внутри `<head>` (сам тег `<link>` подробнее разберём в уроке 9 - сейчас просто используем его для favicon):

```html
<head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
    <link rel="icon" type="image/png" href="favicon.png">
</head>
```

- `rel="icon"` - сообщает браузеру, что это иконка сайта.
- `type="image/png"` - формат файла (может быть также `.ico`, `.svg`).
- `href` - путь к файлу иконки (обычно небольшое квадратное изображение - 32×32 или 16×16 пикселей).

**Классический вариант:** файл `favicon.ico`, лежащий в корне сайта - многие браузеры находят его автоматически даже без явного тега `<link>`, но явное указание - более надёжная и современная практика.

## Итоги урока

Сегодня вы узнали:

- `<img>` - непарный тег для вставки изображений, с обязательными атрибутами `src` и `alt`, а также опциональными `width`/`height` для резервирования места на странице.
- Четыре формата изображений: JPEG (фото), PNG (графика с прозрачностью), SVG (векторная графика, иконки/логотипы), WebP (универсальный современный формат).
- `<figure>`/`<figcaption>` - семантическая связка изображения с его подписью.
- `<audio>` и `<video>` встраивают медиа через один или несколько `<source>`, с атрибутом `controls` для панели управления.
- Favicon подключается через `<link rel="icon">` в `<head>` и отображается на вкладке браузера.
