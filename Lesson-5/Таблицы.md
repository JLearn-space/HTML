## Блок 1. Зачем нужны таблицы и когда их НЕ использовать

**Простыми словами:** таблица в HTML - это то же самое, что таблица в Excel или Word: данные, организованные по строкам (горизонтальным рядам) и столбцам (вертикальным колонкам), где каждая ячейка находится на пересечении конкретной строки и конкретного столбца.

**Правило применения таблиц очень простое:** используйте `<table>`, только если у вас **реально табличные данные** - то есть данные, где важна и строка, и столбец одновременно. Примеры хороших случаев:

- расписание занятий (день недели × время);
- сравнение цен на тарифы (тариф × характеристика);
- турнирная таблица (команда × очки/победы/поражения);
- список учеников с оценками по предметам.

### Важное историческое предупреждение

Много лет назад (в 1990-х – начале 2000-х) веб-разработчики использовали таблицы **для вёрстки макета всей страницы целиком** - то есть, чтобы просто расположить шапку, меню и контент в нужных местах экрана, без всякого отношения к табличным данным. Это называют **"table layout"**, и сегодня это **считается устаревшим и не рекомендуется**, потому что:

- такой код тяжело читать и поддерживать;
- скринридер, встречая `<table>`, ожидает услышать именно данные с заголовками строк/столбцов - а не структуру всей страницы, что сбивает с толку незрячих пользователей;
- современный CSS (который мы изучим позже в курсе) даёт гораздо более гибкие инструменты для расположения блоков на странице.

**Правило простое:** если вы хотите просто "расположить блоки рядом" (например, шапку сверху, меню слева, контент справа) - это задача CSS, а не `<table>`. Таблица - только для настоящих табличных **данных**.

## Блок 2. `table`, `tr`, `td`, `th`

### Базовая структура

```html
<table>
    <tr>
        <th>Имя</th>
        <th>Возраст</th>
        <th>Город</th>
    </tr>
    <tr>
        <td>Азиз</td>
        <td>21</td>
        <td>Ташкент</td>
    </tr>
    <tr>
        <td>Дилноза</td>
        <td>19</td>
        <td>Алмалык</td>
    </tr>
</table>
```

Разберём каждый тег.

### `<table>` - сама таблица

Общая обёртка для всей таблицы целиком. Всё остальное находится внутри неё.

### `<tr>` (table row) - строка таблицы

Каждая горизонтальная строка таблицы - отдельный тег `<tr>`. В примере выше три строки: одна для заголовков столбцов и две для данных.

### `<th>` (table header) - заголовочная ячейка

Обозначает ячейку, которая является **заголовком** для строки или столбца, а не обычными данными. По умолчанию браузер отображает её жирным шрифтом и по центру - но, как мы уже знаем из урока 2, важен не внешний вид, а смысл: `<th>` сообщает браузеру и скринридеру "это заголовок, остальные ячейки в этом столбце/строке относятся именно к нему".

### `<td>` (table data) - обычная ячейка с данными

Все остальные ячейки таблицы, которые содержат сами данные (не заголовки).

**Аналогия:** представьте классный журнал. Верхняя строка с именами предметов ("Математика", "Физика", "История") - это `<th>`, а сами оценки в клетках - это `<td>`. Точно так же в первом столбце имена учеников - тоже `<th>` (заголовки строк), а всё остальное внутри - `<td>`.

### `<th>` не только сверху - может быть и слева

```html
<table>
    <tr>
        <th></th>
        <th>Математика</th>
        <th>Физика</th>
    </tr>
    <tr>
        <th>Азиз</th>
        <td>5</td>
        <td>4</td>
    </tr>
    <tr>
        <th>Дилноза</th>
        <td>4</td>
        <td>5</td>
    </tr>
</table>
```

Здесь заголовки есть и сверху (названия предметов), и слева (имена учеников) - а пустая `<th></th>` в левом верхнем углу нужна просто для того, чтобы сетка таблицы правильно выровнялась (это стандартная практика для таблиц с "двойными" заголовками).

---

### Частые ошибки новичков

| Ошибка                                                                     | Как исправить                                                                                                                                                 |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Используют `<td>` вместо `<th>` для заголовков                             | Заголовки строк/столбцов - всегда `<th>`, а не `<td>` с жирным текстом через другие теги                                                                      |
| Забывают закрывать `<tr>`, `<td>`, `<th>`                                  | Все три тега - парные, не забывайте закрывающие теги                                                                                                          |
| Делают разное количество ячеек в разных строках без причины                | Каждая `<tr>` должна содержать одинаковое количество ячеек (`<td>`/`<th>`), если только вы осознанно не объединяете ячейки через `colspan`/`rowspan` (блок 5) |
| Используют `<table>` для расположения блоков страницы (шапка/меню/контент) | Для вёрстки макета используйте CSS - таблица только для табличных данных                                                                                      |

## Блок 3. `thead`, `tbody`, `tfoot`

Когда таблица становится больше и сложнее, полезно явно разделить её на смысловые части - точно так же, как в отчёте бывает "шапка таблицы", "основные данные" и "итоговая строка".

```html
<table>
    <thead>
        <tr>
            <th>Товар</th>
            <th>Цена</th>
            <th>Количество</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ноутбук</td>
            <td>8 000 000 сум</td>
            <td>1</td>
        </tr>
        <tr>
            <td>Мышь</td>
            <td>150 000 сум</td>
            <td>2</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td>Итого</td>
            <td>8 300 000 сум</td>
            <td>3</td>
        </tr>
    </tfoot>
</table>
```

- **`<thead>`** (table head) - шапка таблицы, обычно строка(и) с заголовками столбцов.
- **`<tbody>`** (table body) - основное "тело" таблицы, где находятся сами данные. Если таблица длинная (много строк), в браузере при прокрутке `<thead>` иногда закрепляют сверху, а `<tbody>` прокручивается - это уже настраивается через CSS, но семантическое деление - основа для такого поведения.
- **`<tfoot>`** (table foot) - подвал таблицы, обычно для итогов (сумма, среднее значение).

**Важно:** это не обязательные теги (простая таблица из блока 2 без них тоже полностью корректна), но для таблиц с реальными данными - хорошая практика, которая явно сообщает браузеру и скринридеру структуру таблицы.

---

### Частые ошибки новичков

| Ошибка                                                                         | Как исправить                                                                                                                                                                                             |
| ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Помещают заголовки столбцов внутрь `<tbody>` вместо `<thead>`                  | Заголовочная строка(и) - в `<thead>`, данные  в `<tbody>`                                                                                                                                                 |
| Указывают `<tfoot>` после `<tbody>` в коде, ожидая, что он отобразится под ним | По спецификации `<tfoot>` можно писать и до, и после `<tbody>` в коде - браузер всё равно отобразит его внизу таблицы визуально, но для читаемости кода принято писать `thead → tbody → tfoot` по порядку |

## Блок 5. `colspan` и `rowspan` - объединение ячеек

Иногда одна ячейка должна "растянуться" на несколько столбцов или строк - например, заголовок, который относится сразу к двум колонкам.

### `colspan` - объединение по горизонтали (столбцы)

```html
<table>
    <tr>
        <th colspan="2">Контактная информация</th>
    </tr>
    <tr>
        <td>Email</td>
        <td>info@saydullayev.fun</td>
    </tr>
    <tr>
        <td>Телефон</td>
        <td>+998 90 123-45-67</td>
    </tr>
</table>
```

`colspan="2"` означает "эта ячейка занимает место двух обычных ячеек по ширине" - поэтому в первой строке всего одна `<th>`, но она визуально растягивается на всю ширину таблицы (замещая собой 2 ячейки).

**Аналогия:** представьте лист в клетку, где вы стираете границу между двумя соседними клетками и пишете один текст на получившемся объединённом пространстве - это именно то, что делает `colspan`.

### `rowspan` - объединение по вертикали (строки)

```html
<table>
    <tr>
        <th>Имя</th>
        <th>Предмет</th>
        <th>Оценка</th>
    </tr>
    <tr>
        <td rowspan="2">Азиз</td>
        <td>Математика</td>
        <td>5</td>
    </tr>
    <tr>
        <td>Физика</td>
        <td>4</td>
    </tr>
</table>
```

`rowspan="2"` означает "эта ячейка занимает место двух строк по высоте" - поэтому имя "Азиз" не повторяется дважды, а показывается один раз напротив обеих его оценок.

**Важное правило при использовании `colspan`/`rowspan`:** как только вы объединяете ячейку на несколько столбцов/строк, в этой строке/столбце должно быть **меньше** обычных ячеек - ровно настолько меньше, сколько "съела" объединённая ячейка. В примере с `rowspan="2"` вторая строка `<tr>` содержит только 2 ячейки (`<td>Физика</td><td>4</td>`), а не 3 - потому что место первой ячейки уже "занято" объединённой ячейкой из первой строки.

---

### Частые ошибки новичков

| Ошибка                                                                  | Как исправить                                                                                                                                                                |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Забывают уменьшить количество ячеек в строке/столбце после объединения  | Если использовали `rowspan="2"` в одной строке - в следующей строке должно быть на одну ячейку меньше                                                                        |
| Путают `colspan` (горизонталь, столбцы) и `rowspan` (вертикаль, строки) | Запомните: col = column = столбец → `colspan` растягивает по столбцам (вширь); row = строка → `rowspan` растягивает по строкам (ввысь)                                       |
| Злоупотребляют объединением ячеек в сложных таблицах                    | Используйте `colspan`/`rowspan` только когда это реально упрощает понимание данных - избыточное объединение усложняет и код, и восприятие таблицы, особенно для скринридеров |

## Блок 6. Доступность таблиц: `caption` и `scope`

### `<caption>` - подпись/название таблицы

```html
<table>
    <caption>Расписание занятий на неделю</caption>
    <thead>
        <tr>
            <th>День</th>
            <th>Предмет</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Понедельник</td>
            <td>Математика</td>
        </tr>
    </tbody>
</table>
```

`<caption>` - первый дочерний элемент внутри `<table>` (сразу после открывающего тега `<table>`, до `<thead>`). Он даёт таблице название - аналог заголовка "Таблица 1. Расписание занятий" в печатном документе. Скринридер озвучивает `<caption>` перед тем, как начать читать содержимое таблицы, - это сразу даёт пользователю понимание, о чём вообще эта таблица.

### `scope` - связь заголовка с данными

Атрибут `scope` у тега `<th>` явно указывает, к чему относится этот заголовок - к столбцу или к строке. Это критично важно для скринридеров: когда пользователь перемещается по ячейкам с данными, скринридер может автоматически озвучивать соответствующий заголовок, "напоминая" пользователю контекст (например: "5, оценка по Математике, у Азиза" - вместо голого "5").

```html
<table>
    <caption>Оценки учеников</caption>
    <thead>
        <tr>
            <th scope="col">Имя</th>
            <th scope="col">Математика</th>
            <th scope="col">Физика</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">Азиз</th>
            <td>5</td>
            <td>4</td>
        </tr>
        <tr>
            <th scope="row">Дилноза</th>
            <td>4</td>
            <td>5</td>
        </tr>
    </tbody>
</table>
```

- `scope="col"` - заголовок относится ко всему **столбцу** под ним.
- `scope="row"` - заголовок относится ко всей **строке** рядом с ним.

**Аналогия:** представьте, что вы объясняете таблицу человеку по телефону, у которого нет возможности её увидеть. Без `scope` вы бы просто перечисляли числа подряд - бессмысленно. А со `scope` вы каждый раз уточняете "это оценка по Математике у Азиза" - именно так работает скринридер благодаря этому атрибуту.

---

### Частые ошибки новичков

| Ошибка                                                                                                | Как исправить                                                                                                                     |
| ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Пропускают `<caption>`, полагаясь только на текст рядом с таблицей (например, `<h2>` перед `<table>`) | Используйте именно `<caption>` внутри `<table>` - он семантически привязан к таблице, в отличие от произвольного соседнего текста |
| Не указывают `scope` у `<th>`                                                                         | Добавляйте `scope="col"` или `scope="row"` - особенно важно для таблиц с заголовками и по строкам, и по столбцам одновременно     |
| Помещают `<caption>` не первым элементом внутри `<table>`                                             | `<caption>` должен идти сразу после открывающего тега `<table>`, перед `<thead>`                                                  |

## Итоги урока

Сегодня вы узнали:

- Таблицы (`<table>`) предназначены для **реальных табличных данных**, а не для вёрстки макета страницы — это устаревшая и не рекомендуемая практика.
- `<tr>` — строка, `<th>` — заголовочная ячейка, `<td>` — ячейка с данными.
- `<thead>`, `<tbody>`, `<tfoot>` смыслово делят таблицу на шапку, тело и подвал.
- `colspan` объединяет ячейки по горизонтали (столбцы), `rowspan` — по вертикали (строки).
- `<caption>` даёт таблице название, а `scope="col"`/`scope="row"` у `<th>` связывает заголовки с данными для скринридеров.
