## Блок 1. Тег `<a>` и атрибут `href`

**Простыми словами:** представьте книгу, в которой написано "подробнее об этом читайте на странице 42". Ссылка в HTML  это то же самое, только вместо "страницы 42" вы указываете адрес другой веб-страницы (или другого места на этой же странице), и переход происходит одним кликом.

Тег `<a>` (anchor - «якорь»)  парный тег, который оборачивает текст (или изображение -  про это в уроке 4), превращая его в кликабельную ссылку.

```html
<a href="https://www.google.com">Перейти на Google</a>
```

Здесь:

- `<a>` - тег ссылки
- `href` (hypertext reference) - атрибут, куда именно ведёт ссылка - **обязательный** атрибут, без него `<a>` не будет работать как ссылка
- `Перейти на Google` - видимый текст ссылки, на который кликает пользователь

**Аналогия:** `<a>` - это дверь, а `href` - это адрес, куда эта дверь ведёт. Без адреса дверь просто нарисована на стене и никуда не открывается.

## Блок 2. Абсолютные и относительные пути

Это ключевая тема урока - многие новички путаются именно здесь.

### Абсолютный путь

**Абсолютный путь** - это полный адрес, включая протокол (`https://`) и домен. Используется для ссылок на **внешние** сайты - то есть не на страницы вашего собственного проекта.

```html
<a href="https://www.wikipedia.org">Википедия</a>
<a href="https://github.com/Saydullayev017">Мой GitHub</a>
```

**Аналогия:** абсолютный путь - это полный почтовый адрес с городом и страной: "Россия, г. Москва, ул. Ленина, 10". Он однозначно понятен из любой точки мира.

### Относительный путь

**Относительный путь** - это адрес, указанный **относительно текущего файла**. Используется для ссылок на **свои же** страницы внутри одного проекта.

**Аналогия:** относительный путь - это как сказать соседу "иди двумя домами дальше" - понятно только если вы уже стоите рядом с исходной точкой. Если вы окажетесь в другом городе, эта инструкция потеряет смысл - а вот полный адрес сработает откуда угодно.

Разберём на примере структуры проекта:

```
html-course/
├── index.html
├── about.html
├── contact.html
└── images/
    └── photo.jpg
```

**Ссылка на файл в той же папке:**

```html
<a href="about.html">О сайте</a>
```

Просто имя файла - браузер ищет его рядом с текущим файлом.

**Ссылка на файл во вложенной папке:**

```html
<a href="images/photo.jpg">Посмотреть фото</a>
```

**Ссылка на файл в папке уровнем выше** (если вы находитесь, например, внутри `images/` и хотите сослаться на `index.html`):

```html
<a href="../index.html">На главную</a>
```

`../` означает «подняться на уровень выше» - как будто выйти из комнаты в коридор.

**Ссылка на саму папку/главную страницу сайта:**

```html
<a href="/">На главную</a>
```

Слэш в начале означает «корень сайта» - если у вас, например, будет сайт `mysite.uz`, ссылка `/` приведёт на `mysite.uz`, а не на файл рядом.

### Когда что использовать

|Ситуация|Какой путь|
|---|---|
|Ссылка на другую страницу вашего же проекта|Относительный|
|Ссылка на внешний сайт (соцсеть, Википедия, чужой сайт)|Абсолютный|
|Ссылка на изображение внутри вашего проекта|Относительный|

**Почему это важно:** если вы используете абсолютный путь для собственных страниц (например, `href="https://mysite.ru/about.html"` вместо `href="about.html"`) - сайт перестанет корректно работать локально при разработке (пока он ещё не опубликован в интернете под этим доменом) и усложнит перенос проекта на другой домен или хостинг.

---

### Частые ошибки новичков

| Ошибка                                                                                 | Как исправить                                                                                                             |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Используют абсолютный путь для своих же страниц: `href="https://mysite.ru/about.html"` | Для страниц внутри своего проекта используйте относительный путь: `href="about.html"`                                     |
| Путают `/about.html` (от корня сайта) и `about.html` (от текущей папки)                | Помните: слэш в начале означает «от корня сайта», без слэша - «от текущего файла»                                         |
| Забывают расширение `.html` в ссылке: `href="about"`                                   | Указывайте полное имя файла с расширением: `href="about.html"`                                                            |
| Ошибаются в регистре имени файла: `href="About.html"` вместо `about.html`              | На большинстве серверов (особенно на Linux/GitHub Pages) регистр важен — имя ссылки должно точно совпадать с именем файла |

## Блок 3. `target="_blank"` - открытие в новой вкладке

По умолчанию ссылка открывается в том же окне/вкладке, заменяя текущую страницу. Если вы хотите, чтобы страница открылась в **новой** вкладке (например, при переходе на внешний сайт, чтобы пользователь не терял ваш сайт) - используйте атрибут `target="_blank"`.

```html
<a href="https://github.com/Saydullayev017" target="_blank">Мой GitHub</a>
```

**Важно про безопасность:** когда вы используете `target="_blank"`, рекомендуется также добавить атрибут `rel="noopener noreferrer"`. Без него открытая новая вкладка технически получает доступ к объекту `window` вашей исходной страницы - это редкая, но известная уязвимость.

```html
<a href="https://github.com/Saydullayev017" target="_blank" rel="noopener noreferrer">Мой GitHub</a>
```

**Правило применения:** используйте `target="_blank"` **только для внешних сайтов**. Для ссылок внутри своего же сайта не открывайте новую вкладку - это неожиданно для пользователя и засоряет его браузер лишними вкладками.

## Блок 4. Якорные ссылки - переход к части страницы

Иногда нужно не перейти на другую страницу, а переместиться к определённому **месту на этой же (или другой) странице** - например, к конкретному разделу длинной статьи.

Это делается в два шага.

**Шаг 1.** Дать элементу, к которому хотим перейти, уникальный идентификатор через атрибут `id`:

```html
<h2 id="section2">Раздел 2. Формы</h2>
```

**Шаг 2.** Создать ссылку на этот `id`, поставив перед именем символ решётки `#`:

```html
<a href="#section2">Перейти к разделу 2</a>
```

При клике браузер плавно (или мгновенно, в зависимости от настроек) прокрутит страницу к элементу с `id="section2"`.

### Пример: содержание длинной статьи

```html
<nav>
    <h3>Содержание</h3>
    <ul>
        <li><a href="#intro">Введение</a></li>
        <li><a href="#history">История</a></li>
        <li><a href="#conclusion">Заключение</a></li>
    </ul>
</nav>

<article>
    <h2 id="intro">Введение</h2>
    <p>Текст введения...</p>

    <h2 id="history">История</h2>
    <p>Текст про историю...</p>

    <h2 id="conclusion">Заключение</h2>
    <p>Заключительный текст...</p>
</article>
```

### Якорная ссылка на раздел другой страницы

Тот же принцип, только сначала указывается файл, потом - `#` и `id`:

```html
<a href="about.html#history">История компании</a>
```

Это откроет `about.html` и сразу прокрутит к элементу с `id="history"`.

### Возврат наверх страницы

Частый приём — ссылка "наверх" в конце длинной страницы:

```html
<a href="#top">Наверх ↑</a>
```

(При условии, что где-то в начале страницы есть элемент с `id="top"`, например `<body id="top">` или первый заголовок.)

**Важное правило про `id`:** значение `id` должно быть **уникальным на всей странице** — не может быть двух элементов с одинаковым `id`. Это отличает `id` от `class` (про `class` подробнее поговорим начиная с урока про CSS).

---

### Частые ошибки новичков

|Ошибка|Как исправить|
|---|---|
|Забывают символ `#` перед именем в ссылке: `href="section2"`|Для якорной ссылки на этой же странице всегда пишите `href="#section2"`|
|Используют одинаковый `id` для нескольких элементов|Каждый `id` на странице должен быть уникальным|
|Используют пробелы в значении `id`: `id="section 2"`|Значение `id` пишется без пробелов, обычно `camelCase` или через дефис: `id="section2"` или `id="section-2"`|
|Путают `id` (уникальный, для одного элемента) и `class` (для группы элементов, разберём позже)|Для якорных ссылок используется именно `id`, не `class`|

## Блок 5. Ссылки для email и телефона

### `mailto:` - открыть почтовый клиент с заполненным адресатом

```html
<a href="mailto:info@saydullayev.fun">Написать нам письмо</a>
```

При клике браузер откроет установленное на устройстве почтовое приложение (например, Outlook, Gmail) с уже заполненным полем "Кому".

Можно сразу задать тему письма:

```html
<a href="mailto:info@saydullayev.fun?subject=Вопрос по курсу">Написать нам письмо</a>
```

### `tel:` — открыть приложение для звонка

```html
<a href="tel:+998901234567">+998 90 123-45-67</a>
```

Особенно полезно на мобильных устройствах — при клике телефон сразу предложит совершить звонок по этому номеру. Номер рекомендуется указывать в международном формате (с `+` и кодом страны), без пробелов и скобок внутри самого атрибута `href` — визуально в тексте ссылки можно форматировать как удобно.

---

### Частые ошибки новичков

| Ошибка                                                                             | Как исправить                                                                                                     |
| ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Забывают `mailto:` и `tel:` перед адресом: `href="info@site.uz"`                   | Всегда указывайте протокол: `href="mailto:info@site.uz"`                                                          |
| Указывают номер телефона с пробелами внутри `href`: `href="tel:+998 90 123 45 67"` | Внутри атрибута пишите номер слитно: `href="tel:+998901234567"`  а форматирование делайте только в видимом тексте |

## Блок 7. Собираем многостраничный сайт со сквозной навигацией

Теперь применим все теги ссылок для того, ради чего они и существуют - связать несколько страниц в единый сайт. Мы создадим три страницы: `index.html`, `about.html`, `contact.html` - с одинаковым меню навигации на каждой.

Структура папки:

```
html-course/
├── index.html
├── about.html
└── contact.html
```

**Файл `index.html`:**

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Главная — Мой сайт</title>
</head>
<body>
    <header>
        <h1>Мой учебный сайт</h1>
        <nav>
            <ul>
                <li><a href="index.html">Главная</a></li>
                <li><a href="about.html">О сайте</a></li>
                <li><a href="contact.html">Контакты</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <h2>Добро пожаловать!</h2>
        <p>Это главная страница моего учебного проекта, который я создаю на курсе «HTML: от А до Я».</p>
        <p>Хотите узнать больше? Перейдите в раздел <a href="about.html">«О сайте»</a>.</p>
    </main>

    <footer>
        <p><small>&copy; 2026 Мой учебный сайт.</small></p>
    </footer>
</body>
</html>
```

**Файл `about.html`:**

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>О сайте — Мой сайт</title>
</head>
<body>
    <header>
        <h1>Мой учебный сайт</h1>
        <nav>
            <ul>
                <li><a href="index.html">Главная</a></li>
                <li><a href="about.html">О сайте</a></li>
                <li><a href="contact.html">Контакты</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <h2>О сайте</h2>
        <p>Этот сайт я создаю в рамках курса по HTML, чтобы на практике закрепить все изученные темы.</p>
        <p>Исходный код проекта можно посмотреть на <a href="https://github.com" target="_blank" rel="noopener noreferrer">GitHub</a>.</p>
    </main>

    <footer>
        <p><small>&copy; 2026 Мой учебный сайт.</small></p>
    </footer>
</body>
</html>
```

**Файл `contact.html`:**

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Контакты — Мой сайт</title>
</head>
<body>
    <header>
        <h1>Мой учебный сайт</h1>
        <nav>
            <ul>
                <li><a href="index.html">Главная</a></li>
                <li><a href="about.html">О сайте</a></li>
                <li><a href="contact.html">Контакты</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <h2>Контакты</h2>
        <p>Свяжитесь со мной удобным способом:</p>
        <ul>
            <li>Email: <a href="mailto:info@saydullayev.fun">info@saydullayev.fun</a></li>
            <li>Телефон: <a href="tel:+998901234567">+998 90 123-45-67</a></li>
        </ul>
    </main>

    <footer>
        <p><small>&copy; 2026 Мой учебный сайт.</small></p>
    </footer>
</body>
</html>
```

**Попробуйте сами:** создайте все три файла, откройте `index.html` через Live Server и прокликайте все ссылки меню - убедитесь, что переходы работают между всеми тремя страницами в обе стороны.

Обратите внимание: меню `<nav>` **дословно одинаковое** на всех трёх страницах - это стандартная практика (в будущем, когда вы изучите более продвинутые технологии, повторяющиеся блоки можно будет выносить в один файл, но на уровне чистого HTML мы пока просто копируем этот блок на каждую страницу).
