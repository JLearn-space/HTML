# Курс «HTML: за 10 уроков» / "HTML: in 10 lessons"

> Курс состоит из **10 тем** и посвящён языку гипертекстовой разметки HTML — от создания первой HTML-страницы до самостоятельной сборки и публикации полноценного веб-проекта. По завершении обучения студент умеет разрабатывать семантически корректные и доступные веб-страницы, а также понимает принципы взаимодействия HTML с CSS и JavaScript.
>
> The course consists of **10 lessons** dedicated to the HTML markup language — from creating your first HTML page to building and publishing a full web project. Upon completion, students can develop semantically correct and accessible web pages, and understand how HTML interacts with CSS and JavaScript.
