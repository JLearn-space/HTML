# Курс «HTML: за 10 уроков»

> Курс состоит из **10 тем** и посвящён языку гипертекстовой разметки HTML - от создания первой HTML-страницы до самостоятельной сборки и публикации полноценного веб-проекта. По завершении обучения студент умеет разрабатывать семантически корректные и доступные веб-страницы, а также понимает принципы взаимодействия HTML с CSS и JavaScript.

## План по блокам

1. **Уроки 1–2:** Фундамент — структура документа, текст, семантика
2. **Уроки 3–5:** Контент — ссылки, изображения/медиа, таблицы
3. **Уроки 6–7:** Формы — сбор данных от пользователя
4. **Уроки 8–9:** Профессиональный уровень — доступность, SEO, мета-теги, связь с CSS/JS
5. **Урок 10:** Итоговый проект — сборка полноценной страницы, чек-лист, публикация
